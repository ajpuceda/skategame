# 🛹 Skate Game

Juego de skate en HTML5 (un solo archivo, sin dependencias).

## Controles
- **⬅️ ➡️ Flechas**: moverte (acelerar / frenar)
- **ESPACIO**: saltar (ollie)
- **Enter**: reiniciar tras game over / meta

## Objetivo
Recorre el camino lleno de huecos y rampas, coge todas las monedas que puedas y llega a la meta. Tienes 3 vidas: si caes en un hueco pierdes una y reapareces en el último tramo seguro.

## Cómo jugar
Abre `index.html` en cualquier navegador, o visita la página de GitHub Pages del repo.

Hecho con Canvas 2D y JavaScript puro.
