# 🛹 Skate Game

Juego de skate urbano en HTML5 (un solo archivo, sin dependencias).

## Controles
- **⬅️ ➡️ Flechas**: moverte (acelerar / frenar)
- **ESPACIO**: saltar (ollie)
- **⬆️ en el aire**: kickflip (+25 puntos)
- **⬇️ en el aire**: voltereta 360 (+50 puntos)
- **Enter**: reiniciar tras game over / meta

## El entorno
Ciudad con skyline de edificios, farolas, papeleras, grafitis en las rampas, aceras con bordillos (salta para subir), plataformas móviles sobre los huecos grandes y pinchos que hay que saltar. Tienes 3 vidas: si caes al vacío o tocas un pincho, reapareces en el último tramo seguro.

## Cómo jugar
Abre `index.html` en cualquier navegador, o visita la página de GitHub Pages del repo.

Hecho con Canvas 2D y JavaScript puro.
